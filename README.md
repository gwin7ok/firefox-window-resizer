# Firefox Window Resizer

ブラウザウィンドウのサイズと位置を、あらかじめ登録した「プリセット」で素早く変更できる Firefox 拡張機能です。Web開発者やデザイナーが、さまざまな画面サイズでウェブサイトを確認するときや、作業用のウィンドウ配置を使い分けたいときに役立ちます。

## 主な機能

- **プリセットでウィンドウを調整**: 幅・高さ・左位置・上位置を登録し、ワンクリックで適用
- **タブを別ウィンドウに分離**: 現在のタブを、指定したサイズ・位置の新しいウィンドウに移動
- **右クリックから直接操作**: リンク、ページ、タブ、ブックマークの右クリックメニューからプリセットを適用
- **複製を別ウィンドウで開く**: タブを複製し、複製だけを別ウィンドウに移動（元のタブは残ります）
- **履歴サイドバー**: 閲覧履歴を日付ごとに表示し、選んだプリセットで別ウィンドウに開く
- **画面の拡大率（DPR）に対応**: 高解像度モニターでも、意図したとおりのサイズになる
- **起動時に自動適用**: ブラウザ起動時に、指定したプリセットを適用

## インストール

[最新リリースのXPI](https://github.com/gwin7ok/firefox-window-resizer/releases/latest/download/gwins-window-resizer.xpi)をダウンロードして、次のいずれかの方法でインストールします（過去のバージョンは [Releases](https://github.com/gwin7ok/firefox-window-resizer/releases) から入手できます）。

- **ドラッグ&ドロップ**: ダウンロードしたXPIファイルを、Firefox のウィンドウにドラッグ&ドロップし、確認ダイアログで「追加」を選びます。
- **アドオン管理画面から**: `about:addons` を開き、歯車アイコンから「ファイルからアドオンをインストール」を選んで、XPIファイルを指定します。

インストール時に「ブックマークの読み取り」「閲覧履歴へのアクセス」などの権限を求められます（用途は[使用する権限](#使用する権限)を参照してください）。

## 使い方

### 1. 設定画面を開く

次のいずれかで開きます。

- ツールバーの拡張機能アイコンをクリックして、ポップアップ下部の「設定」ボタンを押す
- ツールバーの拡張機能アイコンを右クリックして「設定を開く」を選ぶ
- `about:addons` の拡張機能の「設定」を開く

### 2. プリセットを作る

設定画面の「新規プリセット作成」から、プリセットを作成します。

- 名前、幅、高さ、左位置、上位置を入力します。名前には改行も使えます（メニューでは1行で表示されます）。
- 「現在のサイズとポジションを使用」ボタンで、開いているウィンドウの値を取り込めます。
- 一覧では、↑↓ボタンまたはドラッグ&ドロップで順序を変更できます。編集・削除もここから行います。

### 3. プリセットを適用する

**ポップアップから**

- ツールバーの拡張機能アイコンをクリックし、プリセットを選ぶと、現在のウィンドウに適用されます。
- 「現在のタブを別ウィンドウに独立させる形でプリセットを適用する」にチェックを入れると、現在のタブが新しいウィンドウに移動して、そのウィンドウにプリセットが適用されます。

**右クリックメニューから**（メニュー名は「Firefox Window Resizer」で、プリセットが一覧表示されます）

| 右クリックする場所 | 動作 |
|---|---|
| リンク | リンク先を新しいウィンドウで開き、プリセットを適用 |
| ページの背景 | 現在のタブを別ウィンドウに移動し、プリセットを適用 |
| タブ | そのタブを別ウィンドウに移動し、プリセットを適用 |
| ページの背景 / タブ →「複製を別ウィンドウで開く」 | タブを複製し、複製側だけを別ウィンドウに移動してプリセットを適用（元のタブは残る） |
| ブックマーク | ブックマークを新しいウィンドウで開き、プリセットを適用 |

### 4. 履歴を別ウィンドウで開く

ツールバーの拡張機能アイコンを右クリックして「履歴を別ウィンドウで開く」を選ぶと、履歴サイドバーが開きます（Firefox の「表示」→「サイドバー」からも開けます）。

- 履歴は日付ごとのツリーで表示されます（今日だけ開いた状態）。見出しをクリックして開閉できます。
- 上部の検索欄で絞り込めます。
- 項目をクリックするとプリセットの一覧が展開されるので、使うプリセットを選んで別ウィンドウで開きます。項目を右クリックすると、プリセットを直接選べます。
- 「さらに読み込む」で100件ずつ、「すべて読み込む」で残りの履歴をまとめて読み込みます。

## 設定

### 画面の拡大率（DPR）

プリセットの値は、**画面の拡大率を反映した物理ピクセル**で入力します。Windows の「拡大/縮小」を 150% などにしている場合は、設定画面の「拡大率設定」の「ディスプレイの拡大率（%）」に同じ値（100%〜300%）を設定してください。この値をもとに、ブラウザへ渡すサイズが自動的に換算され、4K などの高解像度モニターでも意図したとおりのサイズになります。

### 起動時のプリセット

設定画面の「起動時設定」で、「ブラウザ起動時に適用するプリセット」を選べます。「(この機能を使用しない)」を選ぶと、自動適用しません。

## 動作環境・権限

- Firefox 140.0 以降（Manifest V2 の WebExtensions）
- 開発・動作確認は Windows 環境で行っています。

### 使用する権限

| 権限 | 用途 |
|---|---|
| `storage` | プリセットと設定の保存 |
| `tabs` | タブの取得・移動・複製 |
| `contextMenus` | 右クリックメニュー |
| `bookmarks` | ブックマークのURLの取得（ブックマークの右クリックメニュー） |
| `history` | 履歴サイドバーでの履歴の検索・表示 |

履歴・ブックマークの内容は、端末内で使用するだけで、外部には送信しません。
